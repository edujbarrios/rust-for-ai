# Rust for AI

**Open-source project for exploring and building AI tools with Rust.**

> **Status: early development.** The repository has been initialized, but there is no published library, executable, or installation process yet. Contributions and ideas are welcome.

## Getting started

1. [Star or watch the repository](https://github.com/edujbarrios/rust-for-ai) to follow progress.
2. Read [CONTRIBUTING.md](CONTRIBUTING.md) to propose a feature or contribute.
3. Check [Issues](https://github.com/edujbarrios/rust-for-ai/issues) for discussions and planned work.

Build and usage instructions will be added alongside the first working Rust implementation; no commands are documented until they can be tested.

## Development priorities

- Establish the initial Rust workspace and automated checks.
- Build a small, documented working example before expanding functionality.
- Add tests, examples, and reproducible setup instructions as features are introduced.
- Keep APIs approachable and contributions easy to review.

These are proposed priorities, not completed features or a fixed API roadmap.

## Contributing

Bug reports, suggestions, documentation and code contributions are welcome. See [the contribution guide](CONTRIBUTING.md).
